# Bike-Store-SQL-Analysis
# 🚴 Bike Store Sales Analysis using MySQL

## 📌 Project Overview

This project focuses on analyzing a Bike Store database using MySQL to answer real-world business questions. The analysis covers customer behavior, product performance, sales trends, inventory insights, and staff performance using SQL.

The objective is to demonstrate SQL skills by solving business problems using a relational database.

---

## 🛠️ Tools & Technologies

- MySQL Workbench
- MySQL
- GitHub

---

## 📂 Database Description

The project uses a relational Bike Store database consisting of the following tables:

- Brands
- Categories
- Customers
- Orders
- Order Items
- Products
- Staffs
- Stocks
- Stores

These tables are connected through primary and foreign keys to perform business analysis.

---

## 📊 Business Problems Solved

This project answers the following business questions:

1. Find the total number of products sold by each store.
2. Calculate the cumulative quantity sold for each product over time.
3. Identify the highest-selling product in each category.
4. Find the customer who spent the most on purchases.
5. Find the highest-priced product in every category.
6. Calculate the total orders placed by each customer for each store.
7. Identify staff members who have never made a sale.
8. Find the top three best-selling products.
9. Calculate the median product price.
10. Identify products that have never been ordered.
11. Find staff members whose sales are above the average sales count.
12. Identify customers who have purchased products from every category.
